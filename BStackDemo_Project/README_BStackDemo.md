# BStackDemo - Manual Testing

Manual testing of the BStackDemo e-commerce demo application (https://bstackdemo.com).

## What is in this folder
| File | Purpose |
|---|---|
| `BStackDemo_Test_Plan.docx` | Scope, approach, environment, entry and exit criteria |
| `BStackDemo_Manual_Test_Artifacts.xlsx` | 30 test cases, requirement traceability matrix (RTM), bug reports and execution summary |
| `screenshots/` | Evidence for failed tests and defects |

## Summary
- Test cases designed: 30 (covering 10 requirements)
- Executed: 30  |  Passed: 29  |  Failed: 1  |  Blocked: 0
- Defects logged: 1
- Techniques used: Equivalence Partitioning, Boundary Value Analysis, error guessing, exploratory testing
